# 🎬 Movie Recommendation System

A simple AI-based Movie Recommendation System built using Python. This project recommends movies based on the genre of the movie entered by the user.

## 📌 Project Description

The system takes a movie name as input, identifies its genre, and recommends other movies belonging to the same genre. This demonstrates the basic concept of a content-based recommendation system.

## 🚀 Features

* Recommend movies based on genre
* Case-insensitive movie search
* Reads movie data from a CSV file
* Beginner-friendly AI project
* Simple and efficient implementation

## 🛠️ Technologies Used

* Python
* Pandas
* CSV Dataset

## 📂 Project Structure

## 📊 Dataset

The dataset contains movie names and their corresponding genres.

Example:

movie,genre

Avengers,Action

Iron Man,Action

Titanic,Romance

Interstellar,Sci-Fi

## ▶️ How to Run

1. Install Pandas:

```bash
pip install pandas
```

2. Run the program:

```bash
python movie_recommender.py
```

3. Enter a movie name when prompted.

## 💡 Example Output

Enter a movie name: Avengers

Recommended Movies:

* Iron Man
* Captain America
* Thor

## 🧠 AI Concept Used

This project uses a Content-Based Recommendation approach. Movies are recommended based on similarity in genre.
