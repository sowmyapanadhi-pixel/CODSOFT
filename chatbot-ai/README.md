# 🤖 AI Chatbot

A simple Rule-Based AI Chatbot built using Python. This chatbot responds to user queries using predefined rules and conditional statements.

## 📌 Project Description

The chatbot interacts with users through a command-line interface and provides responses based on specific keywords and questions. It demonstrates the basic concepts of Natural Language Processing (NLP), pattern matching, and conversation flow.

## ✨ Features

- Greets users
- Introduces itself
- Answers basic questions
- Provides study tips
- Explains Python
- Gives motivational messages
- Exit functionality

## 🛠️ Technologies Used

- Python
- If-Else Statements
- String Handling
- Pattern Matching
- Basic NLP Concepts

## 🚀 How to Run

1. Install Python on your system.
2. Save the code as `chatbot.py`.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python chatbot.py
```

## 💬 Sample Interaction

```text
🤖 AI CHATBOT!!!
Type 'bye' to exit.

You: hello
Bot: Hello! Welcome 😊

You: what is python
Bot: Python is a high-level programming language known for its simple, highly readable syntax.

You: motivate
Bot: Believe in yourself and keep learning!

You: bye
Bot: Goodbye! Have a great day 😊
```
