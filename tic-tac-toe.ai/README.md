# 🎮 Tic-Tac-Toe AI

A Tic-Tac-Toe game developed using Python where a human player competes against an AI opponent. The AI uses the Minimax Algorithm to make optimal decisions and is designed to be unbeatable.

## 📌 Project Description

This project implements the classic Tic-Tac-Toe game with Artificial Intelligence. The player plays as **X**, while the AI plays as **O**. The AI evaluates all possible future moves using the Minimax Algorithm and chooses the best move.

## ✨ Features

- Human vs AI gameplay
- Unbeatable AI using Minimax Algorithm
- Win and Draw Detection
- Input Validation
- Command-Line Interface

## 🛠️ Technologies Used

- Python
- Minimax Algorithm
- Artificial Intelligence
- Game Logic
- Recursion

## 🚀 How to Run

1. Install Python.
2. Save the code as `tic_tac_toe.py`.
3. Open terminal in the project folder.
4. Run:

```bash
python tic_tac_toe.py
```
